# TFT Tournament Dashboard

![Tournament Screenshot](https://raw.githubusercontent.com/ancarvalho/RoadToToddy/refs/heads/master/static/img/final.jpeg)

## Core Features

-   **Dynamic Day Parsing**: Automatically detects tournament data for multiple days, including special formats for the "Final Day".
-   **Single Page Application (SPA)**: Navigation between views (Leaderboard, Lobbies) and days without page reloads.
-   **Data-Driven UI**: The interface intelligently adapts to the data, such-as showing the correct number of games per round or displaying a unique "Podium" view for the final results.
-   **Internationalization (i18n)**: Full support for English and Portuguese.
-   **Interactive Modals**: Detailed player statistics, performance charts, and complete match histories.
-   **Custom SVG Charts**: A lightweight, dependency-free SVG charting engine for visualizing player performance.
-   **Responsive Design**: A beautiful and functional experience across all devices, from large desktops to mobile phones.
-   **Cutoff Highlighting**: Players below the advancement cutoff for each day are visually distinguished.
